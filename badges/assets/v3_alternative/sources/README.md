# Alternative vector sources

`dolby.svg` and `dts.svg` are unmodified Simple Icons 13.21.0 source paths:

- https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/dolby.svg
- https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/dts.svg

The Simple Icons collection is distributed under CC0-1.0. Brand rights remain with the respective owners.

`seadex-mark.svg` retains the three curve paths from this repository's `badges/assets/v1_2/v-seadex.svg`, isolated from that old badge's background.

`dts-rings.svg` is a native geometric ring ornament for this style. Source-network wordmarks reuse the nine original SVGs already retained under `badges/assets/v3_frameless/sources/`.

All text, symbols and wordmarks are rendered as clean masks and receive the same sculpted-metal shader. The concept sheet is a design reference; no tiles are cut out of it for import.
